TaskMaster PHP Task Management System

A full-stack PHP application for managing tasks with user authentication, database integration, and responsive design

PHP MySQL HTML5 CSS3 JavaScript Bootstrap

Secure Authentication

Implemented user registration and login system with password hashing using PHP's password_hash() function. Session management ensures secure user access.

Task Management

Full CRUD (Create, Read, Update, Delete) operations for tasks. Users can add, edit, mark as complete, and delete tasks with ease.

MySQL Database

Structured database design with users and tasks tables. Proper SQL queries with prepared statements to prevent SQL injection attacks.

Key Features

User Registration & Login

Secure authentication system with form validation

Task CRUD Operations

Create, read, update, and delete tasks

Priority System

Tasks categorized by priority (High, Medium, Low)

Due Date Tracking
